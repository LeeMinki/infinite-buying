## Why

한국장·미국장 상승률 랭킹 전략은 실제 거래 기록에서 목표 수익 구간을 지나쳤는데도 폴링 평가가 놓치거나, 진입 직후 추세가 무너진 종목을 뒤늦게 손절하는 문제가 확인되었다. 단순히 익절률·손절률 숫자를 바꾸기보다, 주문 실행 구조와 진입 실패 판정, 후보 필터, 분봉 리플레이 검증을 함께 개선해야 한다.

## What Changes

- 한국장·미국장 랭킹 전략 모두 매수 체결 확인 후 목표 수익 지정가 매도 주문을 즉시 제출한다.
- 목표 수익 주문이 이미 접수되어 있으면 스케줄러는 중복 매도 주문을 만들지 않고 체결 여부를 확인한다.
- 보유 중 가격·VWAP·시가·거래량·고점 돌파 흐름이 빠르게 무너지면 목표/손절 숫자 도달 전이라도 "진입 실패"로 판단해 전량 매도를 시도한다.
- 한국장·미국장 랭킹 후보 선정 시 기존 단기 흐름 필터를 강화한다.
  - 매수가능금액으로 1주도 살 수 없는 종목 제외.
  - 급등 후 이미 고점에서 밀리는 종목 제외.
  - 거래량이 꺼지는 종목 제외.
  - 스프레드 또는 호가 품질을 확인할 수 있으면 과도한 스프레드 종목 제외.
  - 한국장은 우선주·관리/투자경고 등 위험 종목을 확인 가능한 범위에서 제외한다.
  - 미국장은 저가·저거래량·과열 급등 후보를 더 보수적으로 제외한다.
- 한국장·미국장 랭킹 전략 전용 분봉 리플레이 분석 기능을 추가한다.
  - 실제 매수·매도 시각 기준으로 KIS 과거 분봉을 조회한다.
  - 매수 후 최대 상승률(MFE), 최대 하락률(MAE), 목표/손절/진입 실패 조건 도달 순서를 계산한다.
  - 익절률·손절률·진입 실패 조건을 바꿨을 때 결과가 어떻게 달라지는지 비교한다.
- 사용자 화면에는 "전략 리플레이" 또는 "거래 복기"로 표시하고, 백테스트와 구분한다.
- 실주문 안전 원칙은 유지한다. 미체결·중복·잔고 부족·보유 수량 부족 시 실제 주문을 보내지 않는다.

## Capabilities

### New Capabilities

- `rank-trading-replay`: 한국장·미국장 랭킹 전략의 실제 거래 기록을 KIS 과거 분봉으로 복기하고, MFE/MAE와 파라미터 변경 결과를 계산한다.
- `us-rank-auto-trading`: 미국장 상승률 랭킹 전략의 목표가 주문, 진입 실패 판정, 후보 필터 강화 요구사항을 명시한다.

### Modified Capabilities

- `kr-rank-auto-trading`: 한국장 상승률 랭킹 전략의 목표가 주문, 진입 실패 판정, 후보 필터 강화 요구사항을 추가한다.
- `auto-trading`: 랭킹 전략 공통 실행 안전장치와 자동매매 화면의 리플레이/복기 진입점을 추가한다.

## Impact

- **Backend**
  - 한국장·미국장 랭킹 서비스의 매수 체결 후 목표가 매도 주문 생성 흐름 변경.
  - 목표가 매도 주문 상태 확인, 미체결 처리, 중복 방지 로직 보강.
  - 보유 중 분봉 기반 진입 실패 판정 로직 추가.
  - KIS 국내 `주식일별분봉조회(FHKST03010230)` 및 해외 과거 분봉 조회를 이용한 리플레이 서비스 추가.
  - 리플레이 결과 저장 여부는 구현 단계에서 결정하되, 기본은 필요 시 계산하는 read-only 분석으로 시작한다.
- **Frontend**
  - 한국장·미국장 랭킹 전략 상세에 거래 복기/리플레이 패널 추가.
  - 목표가 주문이 걸려 있는지, 진입 실패 매도인지, 일반 손절인지 구분해 표시.
- **DB**
  - 목표가 주문 추적에 기존 주문 테이블을 우선 재사용한다.
  - 리플레이 결과 캐시가 필요하면 별도 테이블을 추가하되, 원장 주문/체결 데이터는 변경하지 않는다.
- **External**
  - KIS 과거 분봉 조회 호출량이 늘 수 있으므로 사용자 명시 요청 또는 제한된 범위에서만 호출한다.
