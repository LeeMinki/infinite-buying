- [x] 1.1 한국장·미국장 랭킹 주문 테이블과 repository에서 목표가 주문, 진입 실패 매도, 기존 손절/청산 매도를 구분하는 데 필요한 필드가 충분한지 확인하고 부족한 컬럼 또는 보조 테이블 마이그레이션을 추가한다.

## 2. 목표가 매도 주문 자동 생성

- [x] 2.1 한국장 랭킹 전략에서 매수 체결이 확인되면 평균 체결가 기준 목표가 매도 주문을 한 번만 생성하도록 구현한다.
- [x] 2.2 미국장 랭킹 전략에서 매수 체결이 확인되면 평균 체결가 기준 목표가 매도 주문을 한 번만 생성하도록 구현한다.
- [x] 2.3 실주문 OFF 상태에서는 실제 KIS 주문을 보내지 않고 목표가 주문 예정 기록만 남기며, 실주문 ON 상태에서만 KIS 주문을 호출하도록 테스트를 추가한다.

## 3. 주문 충돌 방지와 체결 확정

- [x] 3.1 목표가 매도 주문이 미체결인 상태에서 손절·진입 실패·강제 청산 조건이 발생하면 목표가 주문 취소를 먼저 시도하고, 취소 확인 전에는 신규 매도를 차단한다.
- [x] 3.2 목표가 주문 접수 상태만으로 보유 상태를 청산 완료로 바꾸지 않고, KIS 체결조회에서 체결 수량과 평균 체결가가 확인된 뒤 주문 이력과 전략 상태를 갱신한다.

## 4. 진입 실패 조기 매도
