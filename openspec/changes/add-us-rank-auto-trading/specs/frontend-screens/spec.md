## ADDED Requirements

### Requirement: 자동매매 화면 미국 랭킹 전략 탭

자동매매 화면(`AutoTradingPage`)은 기존 "라오어 무한매수법"·"한국 국장 상승률 랭킹 전략" 탭 옆에 "미국 국장 상승률 랭킹 전략" 탭을 추가로 제공해야 한다(MUST). 새 탭은 미국 랭킹 전략의 생성·시작·종료·조회 UI만 보여주며, 한 탭의 동작이 다른 탭의 전략에 영향을 주어서는 안 된다. 실주문 실행 설정·KIS 연동은 세 탭이 공유한다.

#### Scenario: 미국 랭킹 탭 진입
- **WHEN** 사용자가 "미국 국장 상승률 랭킹 전략" 탭을 연다
- **THEN** 미국 랭킹 전략의 생성·시작·종료, 연결 계좌(USD 매수가능금액), 매매 사이클·판단 로그·주문 이력 표시 UI가 보여야 한다

#### Scenario: 탭 간 독립성
- **WHEN** 미국 랭킹 탭에서 전략을 시작/종료
- **THEN** 라오어·한국 랭킹 탭의 전략 상태는 바뀌지 않아야 한다

### Requirement: 미국 랭킹 전략 만들기 폼

미국 랭킹 전략 탭의 전략 만들기 폼은 다음 입력을 받아야 한다(MUST): 자동 예산 사용 체크박스(기본 켜짐), 고정 USD 매수 금액(자동 예산이 꺼지면 노출), 익절 기준(%)(기본 2), 손절 기준(%)(기본 5), 등락률 상한(%)(기본 20), 강제 청산 시각(`HH:MM` KST, 기본 `04:30`), 거래소 코드(NASDAQ/NYSE/AMEX/전체 선택, 기본 NASDAQ). 자동 예산이 켜져 있으면 고정 USD 입력은 숨기고 안내문만 표시한다.

#### Scenario: 자동 예산 켜짐 — 매수 금액 입력 숨김
- **WHEN** 사용자가 자동 예산 체크박스를 켠다
- **THEN** 고정 USD 매수 금액 입력 칸이 숨겨지고 "평가 시점 USD 매수가능금액 전액을 한 종목에 투입합니다" 안내문이 노출되어야 한다

#### Scenario: 강제 청산 시각 형식 검증
- **WHEN** 사용자가 강제 청산 시각으로 `25:00` 같은 잘못된 값 입력
- **THEN** 서버가 거절하고 폼에 오류 메시지가 표시되어야 한다

### Requirement: 미국 랭킹 전략 상세 표시

미국 랭킹 전략 상세에는 전략 상태, 익절·손절·등락률 상한·강제 청산 시각, 현재 보유 종목, 오늘 매매 횟수(`trade_seq` 최댓값), 오늘 잠금(`day_locked_out`) 여부, 마지막 판단·평가 시각이 함께 표시되어야 한다(MUST). 또한 매매 사이클 기록 테이블(날짜·번호·종목·진입가·청산가·청산 사유·수익률), 판단 로그(평가금액 컬럼 포함), 주문 이력(총 금액 컬럼 포함)이 표시되어야 한다.

#### Scenario: 오늘 매매 횟수와 잠금 표시
- **WHEN** 그날 3회 매매 후 손절 매도로 day_locked_out
- **THEN** 상세 metric에 "오늘 매매: 3회", "오늘 잠금: 켜짐(손절)" 표시

#### Scenario: 정규장 외 표시
- **WHEN** 평가 시점이 정규장 외(예: KST 12:00)
- **THEN** 상세에 "지금은 미국 정규장 외" 표시 후 새 매매 사이클이 시작되지 않아야 한다
