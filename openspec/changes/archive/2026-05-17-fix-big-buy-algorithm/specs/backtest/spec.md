## ADDED Requirements

### Requirement: 백테스트 큰수 매수 지정가는 평단가 기준

백테스트 엔진(`strategyEngine.js`)은 큰수 매수 지정가를 `평단가 × (1 + bigBuyPremiumRate)`로 계산해야 한다(MUST). 전일 종가(`prevClose`)는 큰수 매수 지정가 계산에 사용하지 않는다. 평단가 매수와 큰수 매수가 동일하게 평단가에 앵커된다.

일봉 체결 규칙은 변경되지 않는다: 일봉 저가가 큰수 매수 지정가 이하이면 체결되며, 체결가는 `min(시가, 큰수 매수 지정가)`이다. 첫 매수(보유 0)는 종전대로 시가 단건 매수로, 본 요구사항의 영향을 받지 않는다.

#### Scenario: 보유 중 큰수 매수 지정가 계산
- **WHEN** 평단가 100, `bigBuyPremiumRate` 0.1로 보유 중인 거래일을 평가
- **THEN** 큰수 매수 지정가는 `100 × 1.1 = 110`이어야 한다
- **AND** 전일 종가 값과 무관해야 한다

#### Scenario: 상승일에 큰수 매수만 체결
- **WHEN** 평단가 100, 큰수 매수 지정가 110, 일봉 `low=104`(평단가 초과, 큰수 지정가 이하)
- **THEN** 평단가 매수는 미체결, 큰수 매수만 회차 예산의 절반으로 체결되어야 한다

#### Scenario: 하락일에 두 절반 모두 체결
- **WHEN** 평단가 100, 큰수 매수 지정가 110, 일봉 `low=95`(두 지정가 모두 이하)
- **THEN** 평단가 매수와 큰수 매수가 각각 회차 예산의 절반으로 체결되어야 한다

### Requirement: 백테스트 큰수 매수 여유율 기본값은 고정 10%

`bigBuyPremiumRate`가 비어 있거나 NULL이면 백테스트는 분할 회차와 무관한 고정 `0.1`(10%)을 사용해야 한다(MUST). 사용자가 명시한 값이 있으면 그 값을 그대로 사용한다(override). 분할 회차는 큰수 매수 여유율에 영향을 주지 않는다.

#### Scenario: 여유율 미입력
- **WHEN** `splitCount=40`, `bigBuyPremiumRate` 미입력으로 백테스트 실행
- **THEN** 큰수 매수 여유율은 `0.1`로 적용되어야 한다

#### Scenario: 분할 회차가 달라도 기본값 동일
- **WHEN** `splitCount=10`, `bigBuyPremiumRate` 미입력으로 백테스트 실행
- **THEN** 큰수 매수 여유율은 여전히 `0.1`이어야 한다

#### Scenario: 사용자 override
- **WHEN** 사용자가 `bigBuyPremiumRate=0.05`를 입력해 백테스트 실행
- **THEN** 큰수 매수 여유율은 `0.05`로 적용되어야 한다
