# Change: Redesign dashboard main workspace

## Why

현재 메인 화면은 중앙 영역이 넓게 비어 있고, 실제 핵심 행동은 왼쪽 사이드바 카드에 몰려 있다.

이로 인해 사용자는 다음과 같은 혼란을 느낄 수 있다.

- 메인 화면에서 무엇을 해야 하는지 명확하지 않다.
- 중앙 영역이 핵심 작업 공간처럼 보이지만 실제로는 안내문만 표시된다.
- 백테스트, 자동매매, KIS 설정 같은 주요 기능이 사이드바 카드에 섞여 있어 우선순위가 약하다.
- "라오어 초안" 같은 부가 요소가 화면을 차지하지만 현재 사용자 행동과 직접 연결되지 않는다.

주식 자동매매 서비스는 사용자가 신뢰와 통제감을 느껴야 하므로, 첫 화면에서 현재 상태와 다음 행동이 즉시 보여야 한다.

## What Changes

메인 화면을 다음 구조로 개편한다.

- 왼쪽 사이드바는 네비게이션과 간단한 상태 요약만 담당한다.
- 중앙 영역은 실제 작업 공간으로 사용한다.
- 중앙 첫 화면에 다음 항목을 배치한다.
  - KIS API 연결 상태
  - 자동매매 실행 상태
  - 선택된 전략
  - 최근 백테스트 결과
  - 최근 주문/체결 또는 실행 로그
  - 주요 행동 카드: KIS 설정, 백테스트 실행, 자동매매 시작
- 최초 사용자 또는 설정 미완료 사용자를 위해 설정 체크리스트를 제공한다.
- 기존 "라오어 초안" 영역은 제거한다.

## Scope

### In Scope

- 대시보드 레이아웃 재구성
- 사이드바 메뉴 단순화
- 중앙 메인 영역에 상태 카드와 주요 액션 카드 추가
- 설정 미완료 상태용 온보딩 체크리스트 추가
- 빈 상태 화면을 행동 중심 empty state로 변경
- 라오어 초안 영역 제거

### Out of Scope

- 자동매매 전략 로직 변경
- 백테스트 계산 로직 변경
- KIS API 연동 방식 변경
- 주문 실행 로직 변경
- 수익률 차트나 고급 리포트 화면 추가
- 모바일 전용 UI 재설계

## User Impact

사용자는 메인 화면에서 즉시 다음을 파악할 수 있다.

- 지금 KIS API가 연결되어 있는지
- 자동매매가 실행 중인지
- 어떤 전략을 사용할 수 있는지
- 백테스트를 바로 실행할 수 있는지
- 자동매매를 시작하기 전에 무엇을 설정해야 하는지

## Success Criteria

- 첫 화면에서 사용자가 5초 안에 주요 행동을 이해할 수 있다.
- 주요 행동 버튼은 중앙 영역에서 확인 가능해야 한다.
- 사이드바는 메뉴와 상태 요약만 포함해야 한다.
- 설정이 안 된 사용자는 KIS 설정을 먼저 해야 한다는 것을 명확히 알 수 있어야 한다.
- 메인 중앙 영역이 빈 공간처럼 보이지 않아야 한다.
