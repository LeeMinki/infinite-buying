## Why

현재 자동매매는 단일 종목 라오어 무한매수법(`LAOR_INFINITE_V2`) 전략 하나만 운용할 수 있다. 사용자는 한국 국장 장중 상승률 상위 종목을 정해진 시각(오전 진입, 선택적 점심 진입)에 매수하고 목표 수익·손절로 빠르게 청산하는, 라오어와 성격이 다른 단타형 전략도 함께 쓰고 싶어 한다. 라오어 전략을 건드리지 않고 자동매매 화면에 별도 전략 탭으로 추가한다.

## What Changes

- 자동매매 화면에 **전략 종류 탭**을 추가한다. 기존 라오어 전략 탭은 그대로 두고 "한국 국장 상승률 랭킹 전략" 탭을 새로 만든다.
- 새 전략 종류 `KR_RANK_MOMENTUM`을 도입한다. 라오어 전략과 **독립적으로** 생성·시작·종료·조회된다.
- 한국주식 등락률 상위 랭킹 조회 기능(KIS 국내주식 등락률 순위 API)을 새로 연동한다.
- 오전 9시 10분 **오전 진입**, 선택 시 11시 30분 **점심 진입** 두 진입 구간을 둔다. 각 진입은 하루 1회, 같은 진입 구간 안에서 1회만 매수한다(매도했어도 같은 구간 재매수 없음). 점심 진입을 켜면 하루 최대 두 번 매수한다.
- 진입 구간별(오전/점심)로 **매수 금액·목표 수익률·손절 기준을 따로 입력**한다. 점심 진입이 꺼져 있으면 오전 값만 쓴다.
- 진입 시 등락률 상위 랭킹에서 등락률 30% 이상 종목을 제외하고 남은 첫 종목을 매수 대상으로 선택, 해당 진입 구간의 매수 금액 한도 안에서 가용 현금을 최대한 써서 매수한다.
- 매수 후 그 진입 구간의 목표 수익률 도달 시 전량 익절, 손절 기준 도달 시 전량 손절한다.
- 진입 시각(09:10·11:30)을 놓치지 않도록 한국 랭킹 전략 스케줄러는 **1분 간격**으로 평가한다(라오어 전략의 10분 간격과 분리).
- 기존 자동매매 **실주문 실행 설정**(`user_trading_settings.live_order_enabled`)·스케줄러·안전 검증·멱등성 구조를 재사용한다. 실주문이 꺼져 있으면 랭킹 조회·종목 선택·판단·주문 예정 기록은 남기되 KIS 주문 API는 호출하지 않는다.
- 진입 구간(오전/점심)·매도 사유(목표 수익/손절)·실주문 여부를 구분해 기록한다.
- 기존 라오어 전략 알고리즘·기록·화면은 **변경하지 않는다**.

## Capabilities

### New Capabilities
- `kr-rank-auto-trading`: 한국 국장 상승률 랭킹 자동매매 전략 — 전략 생명주기, 오전/점심 진입 스케줄, 랭킹 조회·종목 선택, 매수/매도 판단, 중복 주문 방지, 기록 요구사항.

### Modified Capabilities
- `auto-trading`: 자동매매 도메인이 라오어 전략 외에 두 번째 독립 전략 종류를 함께 운용하며, 실주문 실행 설정·스케줄러·안전 검증을 두 전략이 공유한다는 점을 명시 (라오어 전략 동작 자체는 불변).
- `frontend-screens`: 자동매매 화면(`AutoTradingPage`)에 전략 종류 탭이 추가된다.

## Impact

- **DB**: 새 마이그레이션 — 한국 랭킹 전략 테이블(전략, 일자별 진입 기록, 판단/주문 기록은 가능한 한 기존 자동매매 테이블 재사용 또는 전략 종류 컬럼 확장으로 처리). `database-model` 참고 문서 갱신.
- **백엔드**: `marketDataService`/`KisMarketDataProvider`에 등락률 순위 조회 추가, 새 전략 엔진·서비스·라우트, `autoTradingScheduler`가 시각 기반 진입을 평가하도록 확장.
- **프론트엔드**: `AutoTradingPage`에 전략 종류 탭과 한국 랭킹 전략 생성/대시보드 UI 추가.
- **외부 API**: KIS 국내주식 등락률 순위 API 신규 사용.
- **불변**: 라오어 자동매매 엔진(`autoTradingStrategyEngine`), 백테스트, 라오어 전략 화면.
