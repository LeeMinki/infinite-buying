## Why

자동매매 화면은 전략별 기록 구조와 탭 흐름이 서로 달라 실제 매매 결과를 한눈에 비교하기 어렵다. 또한 전략 삭제 시 실행 이력까지 사라질 수 있어 실거래 기록 추적과 손익 복기가 불안정하며, 메인 화면은 사용자가 자주 쓰는 백테스트·자동매매·KIS 설정으로 바로 진입하기 어렵다.

## What Changes

- 한국장 랭킹 전략과 미국장 랭킹 전략은 전략 삭제 시 주문·판단 이력을 보존한다.
- 자동매매 화면 탭 순서를 한국 국장 상승률, 미국장 상승률, 라오어 무한매수법 순서로 변경한다.
- 메인 화면의 왼쪽 사이드 영역(시작 가이드, 공통 전략 초안 등)을 제거하고 백테스트, 자동매매, KIS 설정으로 바로 진입하는 모던한 홈 UI로 교체한다.
- 한국장 랭킹 전략과 미국장 랭킹 전략 상세 화면의 기록 섹션을 `주문 이력`, `판단 로그` 두 테이블 중심으로 정리한다.
- 한국장과 미국장의 주문 이력은 왕복 거래 단위로 매수 시각, 종목, 매수가, 매도 시각, 매도가, 사유, 손익을 보여준다.
- 판단 로그는 처음 10개만 표시하고, 사용자가 `더보기`를 누르면 추가로 불러오거나 표시한다.

## Capabilities

### New Capabilities
- `us-rank-auto-trading`: 미국장 상승률 랭킹 전략의 삭제 시 이력 보존, 왕복 주문 이력 표시, 판단 로그 페이지네이션 요구사항을 정의한다.

### Modified Capabilities
- `auto-trading`: 랭킹 전략 삭제 시 이력 보존 정책과 자동매매 기록 표시의 공통 요구사항을 변경한다.
- `kr-rank-auto-trading`: 한국 국장 상승률 랭킹 전략의 삭제 동작과 상세 기록 테이블 요구사항을 변경한다.
- `frontend-screens`: 자동매매 탭 순서, 홈 화면 구조, 랭킹 전략 상세 화면의 테이블 구성을 변경한다.

## Impact

- Backend: 한국장·미국장 랭킹 전략 삭제 API, 전략 목록 조회, 주문/판단 이력 조회 API, 이력 보존을 위한 status 또는 soft-delete 처리.
- Frontend: 홈 화면, 자동매매 탭 순서, 한국장·미국장 랭킹 상세 화면, 주문 이력 테이블, 판단 로그 더보기 UI.
- DB: 필요 시 전략 테이블에 삭제 상태 또는 삭제 시각 컬럼 추가, 이력 테이블은 삭제된 전략과 연결된 기록을 유지.
- Tests: 전략 삭제 후 주문/판단 이력 보존, 자동매매 탭 순서, 주문 이력 왕복 표시, 판단 로그 10개 표시 및 더보기 동작 검증.
