## MODIFIED Requirements

### Requirement: 자동매매 화면 전략 종류 탭

자동매매 화면(`AutoTradingPage`)은 전략 종류를 선택하는 탭을 제공해야 한다(MUST). 탭 순서는 `한국 국장 상승률 랭킹 전략`, `미국장 상승률 랭킹 전략`, `라오어 무한매수법` 순서여야 한다(MUST). 각 탭은 해당 종류의 전략 생성·시작·종료·조회 UI만 보여주어야 하며, 한 탭의 동작이 다른 탭의 전략에 영향을 주어서는 안 된다. 라오어 무한매수법 전략 탭은 유지하되 자동매매 화면의 첫 노출은 랭킹 전략 중심이어야 한다.

#### Scenario: 한국 랭킹 전략 탭이 먼저 표시됨
- **WHEN** 사용자가 자동매매 화면을 처음 연다
- **THEN** 한국 국장 상승률 랭킹 전략 탭이 첫 번째 탭으로 표시되어야 한다
- **AND** 한국 랭킹 전략의 생성·시작·종료와 주문 이력·판단 로그 UI가 표시되어야 한다

#### Scenario: 미국 랭킹 전략 탭
- **WHEN** 사용자가 미국장 상승률 랭킹 전략 탭을 연다
- **THEN** 미국 랭킹 전략의 생성·시작·종료와 주문 이력·판단 로그 UI가 표시되어야 한다

#### Scenario: 라오어 탭
- **WHEN** 사용자가 라오어 무한매수법 탭을 연다
- **THEN** 종전과 동일한 라오어 전략 생성·운용 UI가 표시되어야 한다

#### Scenario: 탭 간 독립성
- **WHEN** 한 탭에서 전략을 시작/종료
- **THEN** 다른 탭의 전략 상태는 바뀌지 않아야 한다

## ADDED Requirements

### Requirement: 메인 화면은 주요 기능 진입을 우선한다

메인 화면은 왼쪽 사이드에 표시되던 시작 가이드, 공통 전략 초안, 라오어 중심 설명 패널을 제거하고 백테스트, 자동매매, KIS 설정으로 바로 진입할 수 있는 주요 액션 UI를 제공해야 한다(MUST). 자동매매 진입은 한국 국장 상승률 랭킹 전략과 미국장 상승률 랭킹 전략이 잘 보이도록 구성해야 한다.

#### Scenario: 메인 화면 주요 액션
- **WHEN** 사용자가 로그인 후 메인 화면에 진입
- **THEN** 백테스트, 자동매매, KIS 설정으로 이동하는 주요 액션이 첫 화면에서 보여야 한다
- **AND** 시작 가이드와 공통 전략 초안 사이드 패널은 표시되지 않아야 한다

#### Scenario: 자동매매 카드에서 랭킹 전략 노출
- **WHEN** 사용자가 메인 화면의 자동매매 영역을 본다
- **THEN** 한국 국장 상승률 랭킹 전략과 미국장 상승률 랭킹 전략이 자동매매의 주요 선택지로 드러나야 한다

### Requirement: 랭킹 전략 상세 화면은 주문 이력과 판단 로그를 중심으로 보여준다

한국 국장 상승률 랭킹 전략과 미국장 상승률 랭킹 전략의 상세 화면은 기록 섹션을 `주문 이력`, `판단 로그` 순서로 표시해야 한다(MUST). 한국장의 `진입 기록`과 미국장의 `매매 사이클`은 기본 테이블로 별도 노출하지 않아야 한다. 주문 이력은 왕복 거래 단위로 매수 시각(KST), 종목, 매수가, 매도 시각, 매도가, 사유, 손익을 표시해야 한다(MUST).

#### Scenario: 한국 랭킹 상세 기록
- **WHEN** 사용자가 한국 국장 상승률 랭킹 전략 상세를 본다
- **THEN** 주문 이력 테이블이 판단 로그보다 먼저 표시되어야 한다
- **AND** 진입 기록 테이블은 기본 기록 섹션에 표시되지 않아야 한다

#### Scenario: 미국 랭킹 상세 기록
- **WHEN** 사용자가 미국장 상승률 랭킹 전략 상세를 본다
- **THEN** 주문 이력 테이블이 판단 로그보다 먼저 표시되어야 한다
- **AND** 매매 사이클 테이블은 기본 기록 섹션에 표시되지 않아야 한다

#### Scenario: 왕복 주문 이력 컬럼
- **WHEN** 주문 이력 테이블에 매수와 매도가 연결된 거래가 표시됨
- **THEN** 행에는 매수 시각(KST), 종목, 매수가, 매도 시각, 매도가, 사유, 손익이 포함되어야 한다

### Requirement: 판단 로그는 10개 단위로 더보기 표시한다

한국 국장 상승률 랭킹 전략과 미국장 상승률 랭킹 전략의 판단 로그는 처음 10개만 표시해야 한다(MUST). 사용자가 더보기를 누르면 다음 로그 묶음을 추가로 표시해야 한다(MUST).

#### Scenario: 최초 판단 로그 10개 표시
- **WHEN** 전략 상세 화면에 판단 로그가 10개보다 많이 존재
- **THEN** 처음에는 최근 판단 로그 10개만 표시되어야 한다
- **AND** 더보기 버튼이 표시되어야 한다

#### Scenario: 더보기로 추가 표시
- **WHEN** 사용자가 판단 로그 더보기를 누름
- **THEN** 다음 판단 로그 묶음이 기존 목록 아래에 추가되어야 한다
