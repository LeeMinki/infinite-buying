## MODIFIED Requirements

### Requirement: 메인 화면은 주요 기능 진입을 우선한다

메인 화면은 백테스트, 자동매매, KIS 설정으로 이동할 수 있어야 하지만, 로그인 후 첫 화면은 단순 기능 런처가 아니라 운용 현황판이어야 한다(MUST). 상단 메뉴와 중복되는 대형 이동 버튼은 핵심 계좌·손익·전략·주문·오류 상태보다 우선 노출하지 않아야 한다(MUST). 자동매매 진입은 한국 국장 상승률 랭킹 전략과 미국장 상승률 랭킹 전략이 잘 보이도록 구성해야 한다.

#### Scenario: 메인 화면 주요 상태
- **WHEN** 사용자가 로그인 후 메인 화면에 진입
- **THEN** 계좌 상태, 자동매매 상태, 전략별 상태, 최근 주문/오류 상태가 먼저 보여야 한다
- **AND** 시작 가이드와 공통 전략 초안 사이드 패널은 표시되지 않아야 한다

#### Scenario: 보조 액션 표시
- **WHEN** 사용자가 메인 화면에서 다른 기능으로 이동하려 함
- **THEN** 백테스트, 자동매매, KIS 설정으로 이동할 수 있어야 한다
- **AND** 해당 이동 액션은 상단 메뉴와 중복되는 대형 런처처럼 보이지 않아야 한다

#### Scenario: 자동매매 상태에서 랭킹 전략 노출
- **WHEN** 사용자가 메인 화면의 자동매매 상태 영역을 본다
- **THEN** 한국 국장 상승률 랭킹 전략과 미국장 상승률 랭킹 전략 상태가 전략별로 드러나야 한다
