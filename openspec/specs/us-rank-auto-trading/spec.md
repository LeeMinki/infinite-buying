## Requirements
### Requirement: 미국장 목표가 매도 주문

미국장 상승률 랭킹 전략은 실주문 모드에서 매수 체결이 확인되면 평균 체결가와 목표 수익률을 기준으로 목표가 지정가 매도 주문을 즉시 제출해야 한다(MUST). 실주문 실행 설정이 꺼져 있으면 실제 KIS 주문을 보내지 않고 목표가 주문 예정 기록만 저장해야 한다(MUST).

#### Scenario: 미국장 매수 체결 후 목표가 주문 생성

- **WHEN** 미국장 랭킹 전략의 매수 주문이 실제 체결가 50 USD로 확인되고 목표 수익률이 2%
- **THEN** 시스템은 51 USD 기준 목표가 매도 주문을 만들어야 한다
- **AND** 주문 이력에는 목표가 주문임을 구분할 수 있어야 한다

#### Scenario: 미국장 목표가 주문 중복 방지

- **WHEN** 같은 매매 사이클에 이미 목표가 매도 주문이 접수되어 있음
- **THEN** 시스템은 새 목표가 매도 주문을 만들지 않아야 한다

### Requirement: 미국장 방어 매도와 목표가 주문 충돌 방지

미국장 랭킹 전략은 목표가 매도 주문이 미체결인 상태에서 손절, 빠른 손절, 강제 청산, 누적 목표 종료 매도 조건이 발생하면 기존 목표가 주문을 먼저 취소하거나 취소 상태를 확인해야 한다(MUST). 기존 주문 취소 상태가 불확실하면 신규 매도 주문을 보내지 않아야 한다(MUST).

#### Scenario: 목표가 취소 후 손절 매도

- **WHEN** 미국장 목표가 매도 주문이 미체결이고 현재가가 손절 기준에 도달
- **THEN** 시스템은 목표가 주문 취소를 시도해야 한다
- **AND** 취소가 확인되면 손절 매도 주문을 제출해야 한다

#### Scenario: 강제 청산과 목표가 주문 충돌

- **WHEN** 강제 청산 시각에 목표가 매도 주문이 아직 미체결
- **THEN** 시스템은 목표가 주문 취소를 먼저 시도해야 한다
- **AND** 취소 성공 후 강제 청산 매도 주문을 제출해야 한다

### Requirement: 미국장 빠른 손절 조기 매도

미국장 랭킹 전략은 보유 중 손실이 3% 이상이고 최근 분봉 기준으로 진입 흐름이 무너졌다고 판단되면 고정 손절률 도달 전이라도 전량 매도를 시도해야 한다(MUST). 빠른 손절 매도는 일반 손절 또는 강제 청산과 구분해 기록되어야 한다(MUST).

#### Scenario: VWAP 이탈

- **WHEN** 미국장 보유 종목 손실이 3% 이상이고 VWAP 아래로 내려가며 회복하지 못함
- **THEN** 시스템은 빠른 손절 매도 판단을 기록하고 전량 매도를 시도해야 한다

#### Scenario: 급격한 고점 이탈

- **WHEN** 미국장 보유 종목이 최근 고점 대비 설정 비율 이상 빠짐
- **THEN** 손실 기준을 함께 만족하면 시스템은 빠른 손절 매도 판단을 기록해야 한다

### Requirement: 미국장 후보 필터 강화

미국장 랭킹 전략은 매수 후보 선정 시 매수가능금액으로 1주도 살 수 없는 종목, 1 USD 미만 종목, 거래량 기준 미달 종목, 거래대금 기준 미달 종목, 과열 급등 후보, 단기 흐름이 꺾인 후보를 제외해야 한다(MUST).

#### Scenario: 1주 매수 불가능 후보 제외

- **WHEN** 랭킹 상위 종목의 1주 가격이 USD 매수가능금액보다 큼
- **THEN** 시스템은 해당 종목을 제외하고 다음 후보를 평가해야 한다

#### Scenario: 거래량 또는 거래대금 부족 후보 제외

- **WHEN** 후보 종목의 거래량 또는 거래대금이 설정 기준에 미달
- **THEN** 시스템은 해당 종목을 제외하고 거절 사유를 남겨야 한다

#### Scenario: 과열 급등 후보 제외

- **WHEN** 후보 종목의 등락률이 설정된 과열 기준 이상
- **THEN** 시스템은 해당 종목을 제외하고 다음 후보를 평가해야 한다
