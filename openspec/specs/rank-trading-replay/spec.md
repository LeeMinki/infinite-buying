## Requirements
### Requirement: 랭킹 전략 거래 복기

시스템은 한국장·미국장 상승률 랭킹 전략의 실제 주문 이력을 선택해 KIS 과거 분봉으로 거래를 복기할 수 있어야 한다(MUST). 복기는 백테스트가 아니라 이미 발생한 거래를 분석하는 기능이어야 하며, 주문 원장과 체결 원장을 수정해서는 안 된다(MUST).

#### Scenario: 한국장 거래 복기 실행

- **WHEN** 사용자가 한국장 랭킹 전략의 완료된 왕복 주문을 선택해 복기를 실행
- **THEN** 시스템은 KIS 국내 과거 분봉을 조회해 매수 시각부터 매도 후 지정 구간까지의 분봉 분석 결과를 반환해야 한다
- **AND** 기존 주문 가격, 체결 가격, 주문 상태는 변경하지 않아야 한다

#### Scenario: 미국장 거래 복기 실행

- **WHEN** 사용자가 미국장 랭킹 전략의 완료된 왕복 주문을 선택해 복기를 실행
- **THEN** 시스템은 KIS 해외 과거 분봉을 조회해 매수 시각부터 매도 후 지정 구간까지의 분봉 분석 결과를 반환해야 한다
- **AND** KIS가 해당 기간 분봉을 제공하지 않으면 복기 불가 사유를 반환해야 한다

### Requirement: MFE/MAE와 도달 시각 계산

거래 복기 결과는 매수 이후 최대 상승률(MFE), 최대 하락률(MAE), 목표 수익 도달 시각, 손절 도달 시각, 진입 실패 조건 도달 시각을 계산해야 한다(MUST). 1분봉 안에서 고가와 저가의 선후 관계를 확정할 수 없는 경우에는 불확실성을 결과에 표시해야 한다(MUST).

#### Scenario: 목표 수익과 손절이 같은 분봉에 존재

- **WHEN** 한 1분봉 안에서 고가가 목표 수익선을 넘고 저가가 손절선을 넘음
- **THEN** 시스템은 둘 중 무엇이 먼저였는지 확정하지 않아야 한다
- **AND** 결과에 "1분봉 안 선후 관계 불확실" 상태를 표시해야 한다

#### Scenario: MFE와 MAE 계산

- **WHEN** 매수 가격 10,000원인 거래의 보유 구간 고가가 10,500원, 저가가 9,600원
- **THEN** MFE는 +5.0%, MAE는 -4.0%로 계산되어야 한다

### Requirement: 대체 파라미터 비교

시스템은 사용자가 입력한 익절률, 손절률, 진입 실패 조건에 대해 해당 거래가 어떤 결과였을지 비교할 수 있어야 한다(MUST). 이 비교는 분봉 기반 근사이며 실제 주문 체결 보장을 의미하지 않아야 한다(MUST).

#### Scenario: 익절률 변경 비교

- **WHEN** 사용자가 기존 +2% 익절 거래에 대해 +3%, +5% 익절률을 비교 요청
- **THEN** 시스템은 각 익절률 도달 여부와 최초 도달 시각을 반환해야 한다

#### Scenario: 손절률 변경 비교

- **WHEN** 사용자가 기존 -5% 손절 거래에 대해 -3%, -4%, -5% 손절률을 비교 요청
- **THEN** 시스템은 각 손절률 도달 여부와 최초 도달 시각을 반환해야 한다

### Requirement: 복기 호출 제한

시스템은 거래 복기에서 KIS API 호출량이 과도해지지 않도록 사용자 명시 요청에 대해서만 실행하고, 한 번에 분석할 수 있는 거래 수와 기간을 제한해야 한다(MUST). 화면 렌더링만으로 KIS 과거 분봉을 자동 호출해서는 안 된다(MUST).

#### Scenario: 사용자가 버튼을 눌렀을 때만 조회

- **WHEN** 사용자가 자동매매 화면을 열어 주문 이력을 조회
- **THEN** 시스템은 거래 복기용 KIS 과거 분봉 API를 호출하지 않아야 한다

#### Scenario: 거래 수 제한

- **WHEN** 사용자가 제한 수를 초과한 거래 복기를 요청
- **THEN** 시스템은 요청을 거절하거나 허용 범위까지만 분석하고 제한 사유를 반환해야 한다
